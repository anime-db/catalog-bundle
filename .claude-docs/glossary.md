# Glossary — термины и имена

> Только то, что легко трактовать неверно: аббревиатуры, исторический нейминг, сущности с неочевидными именами.

## Доменные сущности

| Имя           | Что это на самом деле                                                                    |
|---------------|------------------------------------------------------------------------------------------|
| **Item**      | Аниме-запись каталога. Единственный настоящий aggregate root.                            |
| **Name**      | НЕ имя поля. Это сущность «альтернативное название аниме» (у Item их много).             |
| **Source**    | Сущность «внешняя ссылка-источник» Item (URL), НЕ источник данных в общем смысле.        |
| **Image**     | Доп. изображение Item. Поле `source` у неё = и значение, и имя файла (двойная роль).     |
| **Storage**   | Хранилище = папка/диск с видеофайлами, которую сканируют. НЕ «хранилище данных/БД».      |
| **Type**      | Тип аниме (TV, OVA, …). Строковый PK (16), без автогенерации, i18n через Gedmo.          |
| **Country**   | Страна. Строковый PK 2 символа (ISO). i18n через personal-translations.                  |
| **Label**     | Пользовательская метка (ManyToMany с Item). НЕ системная категория.                      |
| **Genre**     | Жанр (ManyToMany). i18n через Gedmo `ext_translations`.                                  |
| **Notice**    | Уведомление пользователю (живёт в AppBundle). Скан создаёт Notice при добавлении аниме.  |
| **Widget\\*** | View-модели (`Widget\Item/Genre/Type`) для отображения данных ВНЕШНИХ каталогов, НЕ ORM. |

## Плагины — 7 категорий (легко перепутать)

| Категория       | НЕ путать                                                                              |
|-----------------|----------------------------------------------------------------------------------------|
| **filler**      | Создаёт Item по URL/форме (скрапит источник). «Заполнитель» новой записи.              |
| **search_fill** | Ищет аниме по имени во внешнем источнике → список результатов. Фронт к filler.         |
| **refiller**    | Дозаполняет ОТДЕЛЬНЫЕ поля СУЩЕСТВУЮЩЕГО Item. Не путать с filler (тот создаёт новый). |
| **import**      | Массовый импорт Item[] из файла/формата.                                               |
| **export**      | Экспорт каталога. Фактически маркерный интерфейс (логика экспорта вне плагина).        |
| **item**        | Расширения контекстного меню одного Item (особая сигнатура buildMenu, 2 арг).          |
| **setting**     | Экран настроек. Маркерный интерфейс.                                                   |

`Chain` здесь = «коллекция плагинов по имени» (реестр), **НЕ** chain-of-responsibility. Делегирования по цепочке нет.

## Методы / поля с неочевидным или ошибочным неймингом

| Имя                      | Значение                                                                                                                                 |
|--------------------------|------------------------------------------------------------------------------------------------------------------------------------------|
| **`Item::freez()`**      | Опечатка от «freeze». Заменяет связи на managed-ссылки `EntityManager::getReference()`. Используется при разрешении дубликата из сессии. |
| **`getDafeultPlugin()`** | Опечатка от «Default». Возвращает плагин поиска по умолчанию (`Search\Chain`).                                                           |
| **`not_cleared_path`**   | Транзиентное поле Item: путь ДО срезания префикса хранилища (см. `doClearPath`).                                                         |
| **`old_paths`**          | Транзиент Storage: предыдущие пути, чтобы listener пересоздал `.storage`-маркеры.                                                        |
| **`.storage`**           | Файл-маркер в папке хранилища, содержит id Storage. Создаётся двумя путями (с разными правами — баг B-12).                               |
| **`getCatalogItem()`**   | В `search_fill`: автозаполнение Item ЕСЛИ результат ровно один. Глотает исключения.                                                      |
| **`data-massage`** (JS)  | Опечатка от «message». Текст подтверждения удаления.                                                                                     |
| **`isAllowFile`**        | В ScanStoragesCommand: проверка расширения файла на «разрешено сканировать».                                                             |

## Сервисы и инфраструктура

| Имя                                                        | Что это                                                                                                                               |
|------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------|
| **`ScanExecutor`**                                         | Запускает фоновый скан. Сам НЕ сканирует — отдаёт команду через `CommandExecutor`.                                                    |
| **`CommandExecutor`**                                      | AppBundle. Async-запуск консольной команды через self-HTTP-POST на route `command_exec`.                                              |
| **`command_exec`**                                         | Внутренний route (AppBundle), исполняющий полученную по POST команду. Сюда уходит скан.                                               |
| **`FilenameCleaner`**                                      | Превращает имя медиа-файла в заголовок для поиска (срезает `[..]`, `DVDRip`, `1080p`…).                                               |
| **`LogResponse`**                                          | Инкрементальный «хвост» лог-файла для AJAX-опроса (отдаёт кусок + offset + флаг end).                                                 |
| **`LazyWrite` / `Decorator` / `Export` (Console\\Output)** | Декораторы `OutputInterface`: буфер вывода / pass-through / зеркалирование в файл.                                                    |
| **`PresetOutput` (Console\\Progress)**                     | Адаптер, запоминающий `OutputInterface` для ProgressHelper.                                                                           |
| **`Selector` / `Builder` (Search)**                        | `Selector` создаёт `Builder`; `Builder` держит ДВА QueryBuilder'а (select + total) синхронно через closure.                           |
| **Gedmo**                                                  | DoctrineExtensions: `Translatable` (Type/Genre → общая `ext_translations`) и personal-translations (Country → `country_translation`). |

## События (event names)

| Константа / событие                  | Когда                                                           |
|--------------------------------------|-----------------------------------------------------------------|
| `DETECTED_NEW_FILES`                 | Скан нашёл неизвестный файл                                     |
| `ADD_NEW_ITEM`                       | Плагин резолвил аниме → добавить в БД                           |
| `UPDATE_ITEM_FILES`                  | Файл существующего Item изменился (mtime новее)                 |
| `DELETE_ITEM_FILES`                  | Файл Item пропал                                                |
| `INSTALL_APP` / `INSTALL_SAMPLES`    | Шаги мастера установки (финал / загрузка sample-аниме)          |
| `anime_db.package.installed/updated` | Composer-события пакета (→ `Listener\Package` копирует шаблоны) |
