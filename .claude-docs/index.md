## Разделение `.claude-docs/` vs `docs/`

- **`.claude-docs/`** (этот каталог) — для агента: ловушки, термины, операционный контекст. Кратко, без воды.
- **`docs/`** — полноценная документация и аудит: подробно, с диаграммами и `file:line`.

При конфликте — `docs/` авторитетнее по фактам, `.claude-docs/` авторитетнее по «как не наступить на грабли».
